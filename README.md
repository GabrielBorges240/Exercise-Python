# Python: Exercises and Study Notes

Repository with the solved exercises and the study notes I wrote while
taking the Python course from Curso em Vídeo, taught by Professor
Gustavo Guanabara.

## Contents

- **Exercises:** 95 exercises organized by folder, following the order
  of the course modules (called "Worlds" or *Mundos*).
- **Notes:** summaries and observations for each lesson, with the main
  concepts and examples.

## Structure

    ├── exercises/
    │   ├── world01/
    │   ├── world02/
    │   └── world03/
    └── notes/
        ├── world01/
        ├── world02/
        └── world03/
